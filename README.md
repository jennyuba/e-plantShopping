# e-Plant Shopping Application

## Project Description

e-Plant Shopping is a React-based online plant shopping application. 
The application allows users to browse a collection of plants, view 
plant information, add plants to a shopping cart, and manage items 
in their cart.

## Features

- Browse available plants
- View plant information
- Add plants to the shopping cart
- Increase or decrease the quantity of plants
- Remove plants from the shopping cart
- View the total cost of items in the cart
- Navigate between the shopping page and cart

## Technologies Used

- HTML
- CSS

- Git
